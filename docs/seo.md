# SEO домщенков.рф

Боевой адрес: `https://домщенков.рф` (в punycode `https://xn--b1adduihee9g.xn--p1ai`, так он записан в canonical,
sitemap и разметке). Превью на GitHub Pages закрыто от индексации, канонический адрес у всех страниц — боевой.

## Что делает сборка (`tools/build.py` → `tools/seo.py`)

На каждой странице (вместо `<!--seo-->` в `base.html.j2`):

| Что | Откуда |
|---|---|
| `<title>`, `meta description`, один `<h1>` | контекст маршрута; сборка предупреждает: title > 60, description > 160 или < 70 знаков, H1 ≠ 1 |
| `link rel=canonical` | `site.seo.base_url` + адрес страницы |
| `meta robots` | `index, follow, max-image-preview:large`; `noindex, follow` — страницы из `site.seo.noindex` (политика конфиденциальности) и 404 |
| Open Graph + `twitter:card` | title без « \| домщенков.рф», description, адрес, первое фото страницы (или `og_image` в контексте, иначе `assets/img/og/og-default.jpg`) |
| Иконки | `favicon.ico` (16/32/48), `assets/icons/favicon.svg`, `apple-touch-icon.png` (180), `icon-192/512`, maskable 512, `site.webmanifest` |
| Коды подтверждения | `site.seo.yandex_verification`, `site.seo.google_verification` — пустые не выводятся |
| Яндекс Метрика | `site.seo.yandex_metrika` — номер счётчика; пустой — счётчика нет |
| JSON-LD | `BreadcrumbList` на всех внутренних страницах; `WebSite` + `PetStore` (организация) на главной и в контактах; страницы сами добавляют `FAQPage` (блок вопросов) и `BlogPosting` (статьи) |
| Защита превью | на `*.github.io` скрипт дописывает `noindex, nofollow` |

Файлы в корне:

- `sitemap.xml` — индексируемые **выложенные** страницы (`src/data/publish.json`, см. «Выпуск по этапам» в brief);
  ссылки на ещё не выложенные страницы получают `rel="nofollow"` и не ведут роботов в 404; `lastmod` — день, когда страница последний раз изменилась
  (хеш хранится в `.build-manifest.json → lastmod`; смена только версии CSS/JS дату не двигает);
  `priority`/`changefreq` по типу страницы (главная 1.0, каталог и породы 0.9, окрасы и цены 0.8, щенки 0.7…).
- `robots.txt` — всё открыто, кроме `/_kit/`; для Яндекса `Clean-param` для фильтров каталога
  (`breed`, `sex`, `status`), тем блога (`tema`) и рекламных меток; ссылка на sitemap.
- `404.html` — своя страница «Страница не найдена» (noindex): ссылки на каталог, главную и четыре породы.
  Работает на любой глубине адреса и на превью (сама ставит `<base>`).
- `site.webmanifest` — название, цвета и иконки.

## Правила для страниц

- Один H1 с главным запросом страницы, до двух строк. Title — запрос + «в Москве», где уместно, ≤ 60 знаков.
  Description — 110–160 знаков, со смыслом и призывом.
- Микроразметка — только того, что есть на странице. `Product`/`Offer` не ставим, пока на сайте нет цен
  (без цены Google и Яндекс считают разметку товара ошибочной). Рейтинг организации — только с настоящими отзывами.
- Картинкам с содержанием — осмысленный `alt`; декоративным (кружки-лица, миниатюры галереи) — `alt=""`.

## Запуск сайта — по шагам

1. Домен `домщенков.рф` → A-запись на IP сервера (и `www` тоже).
2. Сервер: по шагам в [`DEPLOY.md`](../DEPLOY.md) (`server-setup.sh`, затем `deploy.sh`). nginx ставится из
   `backend/deploy/nginx.conf`: правила отсюда (один адрес, 404, кэш, gzip) + API форм и админ-панель.
   `deploy.sh` сам проверяет: `/maltipu/index.html` → `/maltipu/`, несуществующий адрес — код 404 и наша страница.
   Вручную: `http://` и `www` ведут на `https://домщенков.рф/` одним 301; `/maltipu` → `/maltipu/`.
3. Заменить заглушки в `src/data/site.json`: телефон, почта, адрес, ссылки мессенджеров, рейтинги — они уходят
   в разметку организации. Пересобрать.
4. **Яндекс Вебмастер**: добавить `https://домщенков.рф`, подтвердить мета-тегом (код → `site.seo.yandex_verification`),
   отправить `sitemap.xml`, указать регион «Москва», связать с карточкой в Яндекс Бизнесе.
5. **Яндекс Бизнес**: карточка питомника (адрес, телефон, часы, фото, сайт) — для Карт и локальной выдачи.
6. **Google Search Console**: подтвердить (код → `site.seo.google_verification`), отправить sitemap.
7. **Яндекс Метрика**: создать счётчик, номер → `site.seo.yandex_metrika`, настроить цели на отправку заявок.
8. Через 1–2 недели: в Вебмастере — ошибки индексации и разметки, в Метрике — первые визиты.
