# Логотип домщенков.рф: варианты

Семь направлений логотипа. Каждое проверено в шапке сайта (40 px, телефон 34 px), на иконке 16–32 px,
на тёмном и коралловом фоне и в один цвет. Два независимых жюри (бренд и качество исполнения) оценили
первый раунд, пять лучших вариантов доработаны по их замечаниям, затем все варианты оценены заново.

Логотип пока не стоит на сайте: шапка, фавикон и иконки меняются после выбора варианта.

## Итог (оценка из 10, финальная)

| место | вариант | папка | оценка | коротко |
|---|---|---|---|---|
| 1 | Эмблема | `concepts/04-emblema/` | 8 | одна линия: крыша и висячие уши щенка; книжная антиква Literata; круглая печать для документов |
| 2 | Родной сайту | `concepts/05-rodnoj/` | 7,5 | спящий щенок на коралловой плитке, название шрифтом сайта Geist; встаёт в шапку без переделок |
| 3 | Дом-лапа | `concepts/02-dom-lapa/` | 7 | лапа, где главная подушечка — домик; самый аккуратный, но мотив частый |
| 4 | Щенок в буквах | `concepts/03-harakter/` | 6,5 | в «о» слова «дом» живёт вислоухий щенок; жирная надпись |
| 5 | Пухлый | `concepts/01-puhlyj/` | 5,5 | ближе всех к референсу «paws!»: пухлая синяя надпись, домик в «о» |
| 6 | Четыре породы | `concepts/06-chetyre-porody/` | 4,5 | четыре подушечки лапы в четырёх цветах пород; во втором раунде не дорабатывался |
| 7 | От руки | `concepts/07-ot-ruki/` | 4 | рукописный Caveat с крышей над «дом»; во втором раунде не дорабатывался |
| — | Сейчас на сайте | `concepts/00-current/` | 3 | коралловая плитка с типовой лапой |

Лучший в целом — «Эмблема», лучший для шапки сайта — «Родной сайту», ближе всех к референсу — «Пухлый».
Оценки — мнение жюри, а не замер на покупателях: перед запуском стоит показать 2–3 финалиста 5–10 людям из аудитории.
Подробности, плюсы и минусы: `results-polish.json` (финальная оценка), `results.json` (первый раунд), `verdict.json` (рекомендация).

## Как пересобрать

Каждый вариант собирается одним скриптом `concepts/<вариант>/work/build.py`; он перезаписывает все SVG варианта.

```
sh docs/logo/tools/get_fonts.sh                            # шрифты (OFL) -> docs/logo/fonts/, в git не попадают
pip install uharfbuzz fonttools                            # для tools/text2path.py
python3 docs/logo/concepts/05-rodnoj/work/build.py         # пересобрать вариант
node docs/logo/tools/proof.mjs docs/logo/concepts/05-rodnoj   # proof.png (Playwright + Chromium)
node docs/logo/tools/compare.mjs out.png                   # все варианты рядом
python3 docs/logo/tools/make_page.py out.html              # страница-презентация
```

`tools/text2path.py` переводит текст в контуры (HarfBuzz, вариативные шрифты); `--help` описывает параметры.
Скрипты `.mjs` ищут Playwright в `/opt/node22/lib/node_modules/playwright`; на другой машине поправьте путь в начале файла.
