- Цель сайта: заявки на щенков. Потом сильное SEO в Яндексе и Google.
- Этап сейчас: только фронтенд главной. Без бэкенда, без SEO-настроек. Статичные HTML/CSS/JS, кликабельный прототип.

## Решение клиента

- Из трёх вариантов ближе всего A и B. Вариант C удалён.
- Собираем **один** вариант. Основа — **аккуратность A**: сетка, отступы, белые плитки, спокойная типографика.
- Из **B** берём акценты и **стиль фото и карточек**: студийные фото, которые «растворяются» в цветной плитке; карточки щенков на цветной подложке; цветные кружки-иконки; яркие карточки «С чем поможем».
- **Текста слишком много.** Главная должна быть лёгкой: короткие заголовки, одна строка подписи, меньше блоков. Подробности уходят на внутренние страницы (ссылки уже есть в архитектуре).
- Фото должны быть чёткими. Оригиналы — в `assets/img/` с теми же именами.

Варианты A и B удалены 12.10 после одобрения объединённой главной.

**Решение клиента 12.10, вечер:** первый экран — общий (четыре щенка всех пород); блок пород — пастельные плитки со студийными фото; цвета акцентов — пастель. Главная одобрена: «Отлично выглядит, в этом же стиле продолжай все остальные страницы».

Плитка под студийным фото: `background: linear-gradient(180deg, var(--tone) 0 55%, var(--tone-floor) 100%)`, фото прижато к низу плитки, края фото гасятся мягкой радиальной маской. Видимый прямоугольник или ореол вокруг собаки — брак.

**Кнопки:** основная — чёрная пилюля `--ink` с белым текстом. Вторичная — белая пилюля с тонкой обводкой. Цветной акцент — только на точках, иконках, ховерах. Контраст текста кнопок ≥ 4.5:1.

**Форма:** радиус плиток 28 px, внутренних фото 20 px, кнопки — пилюли. Зазор сетки 10 px. Поля страницы `clamp(16px, 3.6vw, 56px)` → 52 px на 1440. Отступ между секциями `clamp(64px, 7vw, 112px)`.

**Типографика (замечание клиента 12.10):** без капса и без жирных начертаний — «выдаёт ИИ». Geist только 400 и 500: заголовки, цифры, кнопки — 500, текст — 400. H1 clamp(40px, 5vw, 80px), line-height .95, −0.035em. H2 clamp(30px, 3.2vw, 52px), −0.03em. Текст 16/1.5. Подписи 14 px. Иерархия — размером, цветом и воздухом, не весом.

**Акценты из B (умеренно):** цветные круглые иконки у цифр доверия и у карточек «С чем поможем»; один повёрнутый стикер на первом экране («Метрика РКФ и договор» или «Растим дома»); цветные круглые кнопки мессенджеров в шапке; цветные точки статусов. Бегущую строку **не делаем** — шумно.

## Интерактив

- Модалка «Узнать цену»: заголовок с кличкой щенка, имя, телефон с маской +7, способ связи (Telegram / WhatsApp / Звонок), согласие, успех. На мобиле — шторка снизу. Esc, фокус-ловушка, возврат фокуса.
- Фильтр щенков, аккордеон FAQ (`aria-expanded`), «Читать полностью».
- Меню «Породы» (ховер и клавиатура), бургер с полноэкранным меню.
- Нижняя липкая панель на мобиле (Позвонить · Telegram · Узнать цену) появляется, когда кнопки первого экрана ушли из вида.
- Тост для ещё не сверстанных страниц.
- `prefers-reduced-motion`. Мягкое появление блоков при скролле.

## Качество

- Один `h1`, `h2` у каждой секции, семантика, `lang="ru"`, title и description из content/home.md.
- У всех `img`: alt по-русски, width/height, lazy (кроме первого экрана — `fetchpriority="high"`), `object-fit: cover`.
- Нет горизонтального скролла на 360–1920. Проверено на 1440, 1024, 768, 390.
- Видимый фокус. Контраст ≥ 4.5:1 для текста.
- Только светлая тема.
