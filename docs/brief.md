# Бриф: главная страница Puppy House — 3 варианта дизайна

## Проект

- Сайт питомника: продажа щенков 4 пород. Мальтипу, французский бульдог, той-пудель, бордер-колли.
- Домен: puppyhouse.ru. Кириллическое зеркало: домщенков.рф.
- Бренд: **Puppy House**. Подпись: «питомник щенков · Москва».
- Цель сайта: заявки на щенков. Потом сильное SEO в Яндексе и Google.
- Этап сейчас: только фронтенд главной. Без бэкенда, без SEO-настроек. Статичные HTML/CSS/JS, кликабельный прототип.
- Цен на сайте нет. Везде кнопка **«Узнать цену»**. Она открывает форму заявки.

## Общие требования ко всем вариантам

### Сетка и отступы
- Бенто-сетка во всю ширину экрана.
- Боковые поля страницы: 40–60 px на десктопе. Рекомендация: `padding-inline: clamp(16px, 3.6vw, 56px)` → 52 px на 1440. На мобиле 16–20 px.
- Без узкого центрированного контейнера. На 1920+ сетка тянется, поля до 56–64 px.
- Зазоры между плитками 8–16 px. Скругления плиток — по стилю варианта.

### Шрифты
- Только Google Fonts с кириллицей: Inter, Geist, Onest, Manrope, Jost, Unbounded. `preconnect` + `display=swap`.
- Иконки — инлайн SVG, простые линейные. Никаких иконочных шрифтов и внешних JS-библиотек.

### Секции главной (все обязательны, порядок — по варианту)
1. Шапка: логотип, меню (Щенки, Породы ▾ с 4 породами, Доставка, Отзывы, О питомнике, Контакты), телефон, мессенджеры, кнопка-CTA. На мобиле — бургер и полноэкранное меню.
2. Первый экран: H1 с ключом «купить щенка в Москве» / «питомник». Подзаголовок, 2 CTA («Смотреть щенков», «Подобрать породу»), блок доверия (цифры).
3. **Породы — как на скриншоте 1**: крупные вертикальные фото-плитки. Огромный белый заголовок КАПСОМ слева сверху (ПИТОМЦЫ-стиль, геометрический гротеск). Под ним 1–2 строки описания мелким белым. Плитка — ссылка на хаб породы. Плюс счётчик «В наличии: N щенков» и стрелка. Мягкий зум фото по ховеру.
4. Щенки в наличии: 8 карточек, фильтр-чипсы по породам (работают на JS), без цен, кнопка «Узнать цену» на каждой. Ссылка «Весь каталог».
5. «Что вы получаете» / «С чем поможем» — яркие цветные карточки с фото, как блок «С чем помогаем» на dobriyhvost.ru: аккуратные насыщенные цвета, качественные фото, тёплый текст.
6. Как купить: 4 шага.
7. Родители и выпускники.
8. Подбор породы: сравнение 4 пород (размер, шерсть, активность, для детей, для квартиры) + CTA на тест.
9. Доставка по России: фото, города, сроки.
10. Щенок в подарок (сезонная плитка) + стартовый набор.
11. Отзывы.
12. Блог: 3–4 статьи.
13. FAQ — аккордеон.
14. SEO-текст: виден первый абзац, остальное по кнопке «Читать полностью».
15. Финальная форма заявки.
16. Подвал: все разделы архитектуры, контакты, мессенджеры, реквизиты-заглушки.

### Интерактив (ванильный JS, без библиотек)
- Модалка «Узнать цену»: имя, телефон с маской +7, способ связи (Telegram / WhatsApp / Звонок), согласие. Кличка щенка подставляется из карточки. Отправка → экран «Спасибо». Сети нет.
- Фильтр щенков по породам.
- Аккордеон FAQ (`aria-expanded`).
- Мобильное меню, выпадающее меню «Породы».
- Нижняя липкая панель на мобиле: «Позвонить», «Telegram», «Узнать цену».
- Тост для ещё не сверстанных страниц.
- Esc закрывает модалку и меню. `prefers-reduced-motion` отключает анимации.

### Качество
- Один `h1`. `h2` у каждой секции. Семантика: `header`, `nav`, `main`, `section`, `footer`.
- У всех `img`: `alt` по-русски, `width`/`height`, `loading="lazy"` (кроме первого экрана: `fetchpriority="high"`), `object-fit: cover`.
- Нет горизонтального скролла на 360–1920 px.
- Проверено на 1440, 1024, 768, 390.
- Видимый фокус. Контраст текста на фото — через градиент-подложку.
- Только светлая тема сайта.
