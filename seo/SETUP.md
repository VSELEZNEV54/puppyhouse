# Доступы к сервисам — см. `2-ДОСТУПЫ-К-API.md`

Инструкция по доступам лежит в корне пакета: **[2-ДОСТУПЫ-К-API.md](docs/2-ДОСТУПЫ-К-API.md)**.

Этот файл оставлен потому, что на него ссылаются сообщения об ошибках самих
инструментов («Полная инструкция по всем доступам: seo/SETUP.md»).
Номера разделов в их подсказках совпадают с номерами разделов того документа:
1 — Яндекс, 2 — Google Search Console, 3 — PageSpeed, 5 — Bing, 6 — Директ.

Коротко, если нужно прямо сейчас:

```bash
cp seo/.env.example seo/.env && chmod 600 seo/.env   # куда вписывать ключи
cp seo/project.example.json seo/project.json         # чем проект отличается
node seo/cli/doctor.mjs                              # что уже работает
```
