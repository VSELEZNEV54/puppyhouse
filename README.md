# Puppy House — прототип главной

Статичный фронтенд сайта питомника щенков: мальтипу, французский бульдог, той-пудель, бордер-колли.
Три варианта дизайна главной на одних и тех же текстах.

### Включить GitHub Pages (один раз)

1. Репозиторий → **Settings** → **Pages**.
2. **Build and deployment → Source:** *Deploy from a branch*.
3. **Branch:** `claude/cool-pasteur-fyuv3z`, папка `/ (root)` → **Save**.
4. Через 1–2 минуты сайт откроется по ссылке выше. Каждый новый пуш в ветку обновляет сайт сам.

В корне лежит `.nojekyll`: GitHub отдаёт файлы как есть, без сборки Jekyll.

### Локально

```bash
python3 -m http.server 8765
# http://127.0.0.1:8765/
```

## Что кликается

- Фильтр щенков по породам.
- «Узнать цену» на карточке: форма с кличкой щенка, маской телефона, выбором мессенджера, экраном «Спасибо». Данные никуда не отправляются.
- FAQ-аккордеон, «Читать полностью» у SEO-текста.
- Меню «Породы», бургер-меню и нижняя панель на мобиле.
- Ссылки на внутренние разделы (`/maltipu/`, `/dostavka/` и т. д.) ведут на будущие страницы. Пока они показывают подсказку «Раздел появится на следующем этапе».

## Структура

```
index.html          страница выбора варианта
variant-a/          вариант A: index.html, style.css, script.js
variant-b/          вариант B
variant-c/          вариант C
content/home.md     все тексты главной + ключи по блокам + список заглушек
docs/brief.md       бриф: архитектура URL, фото, требования
assets/img/         фото (сгенерированы под прототип)
assets/previews/    превью вариантов для страницы выбора
tools/              манифест фото, скрипт загрузки оригиналов, скрипт превью
```

## Фото

Фото сгенерированы под прототип. Сейчас в `assets/img/` лежат превью в низком разрешении, поэтому они немного мягкие.
Оригиналы скачиваются командой `python3 tools/fetch_images.py` (нужен доступ к `www.figma.com`, ссылки действуют до 19.10.2026).
Перед запуском сайта фото заменяются реальными фото щенков питомника с теми же именами файлов.

## Заглушки

Телефон, адрес, реквизиты, отзывы, цифры доверия и количество щенков — примеры для макета.
Полный список — в конце `content/home.md`, раздел «Заменить реальными данными».
